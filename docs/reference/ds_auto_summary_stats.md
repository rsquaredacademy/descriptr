# Descriptive statistics and frquency tables

Generate summary statistics & frequency table for all continuous
variables in data.

## Usage

``` r
ds_auto_summary_stats(data, ...)
```

## Arguments

- data:

  A `data.frame` or `tibble`.

- ...:

  Column(s) in `data`.
