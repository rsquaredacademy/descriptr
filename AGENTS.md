# AGENTS.md

R package `descriptr` (CRAN): descriptive statistics, frequency/cross tables,
group summaries, and ggplot2-based plots. Single-package repo, no monorepo tooling.

## Commands

Run from the package root inside R:

```r
devtools::load_all()                      # source the package
devtools::test()                          # all tests (testthat edition 3)
devtools::test(filter = "plots")          # one file: tests/testthat/test-plots.R
devtools::check()                         # full R CMD check incl. vignettes
devtools::document()                      # regenerate NAMESPACE + man/
devtools::build_readme()                  # rebuild README.md from README.Rmd
```

## Generated files — do not edit by hand

- `NAMESPACE`, `man/`: generated by roxygen2 from `#'` comments in `R/*.R`. Edit the roxygen comments, then run `devtools::document()`.
- `README.md`: generated from `README.Rmd`. Edit `README.Rmd`, then rebuild.
- `docs/`: committed pkgdown site build (GitHub Pages), configured by `_pkgdown.yml`.

## Testing gotchas

- Plot tests use **vdiffr** SVG snapshots in `tests/testthat/_snaps/`. Intentional plot changes fail as doppelganger diffs; re-accept with `vdiffr::manage_cases()` or delete the affected `_snaps/**.svg` and rerun.
- Plot functions take `print_plot = FALSE`; tests always pass it and snapshot the returned object.
- Tests assert **exact error strings** (`expect_error(..., 'Data has no continuous variables.')`). Changing a message requires updating the matching test.
- `tests/README.md` is a stale covrpage report from 2019 (references deleted `dist_*.R` files). Ignore it.

## Conventions

- Exported functions are prefixed `ds_`; helpers in `R/ds-utils.R`, `R/ds-output.R` etc. are internal (unexported).
- Functions accept either a data frame + tidy-selected columns (`...`) or a bare vector; validate data frames with `check_df()` (`R/ds-utils.R`) and raise errors via `stop(msg, call. = FALSE)`.
- Use the bundled dataset `mtcarz`, not base `mtcars`: same numbers but categorical columns are factors — tests/examples depend on this. `hsb` is the other bundled dataset.
- magrittr is imported wholesale; `%<>%` compound assignment appears in existing code. ggplot2/stats are fully imported (no `::` needed there).
- S3 pattern: results return objects of class `ds_*` with `print.` / `plot.` methods in `R/ds-output.R` / `R/ds-plots.R`.
- Versioning: `x.y.z.9000` = development. Add changes under "# descriptr (development version)" in `NEWS.md`; see `cran-comments.md` for CRAN submission notes.

## Git workflow

- Default working branch: `develop`; releases merge to `master`. CI (R-CMD-check across macOS/Windows/Ubuntu, r-release/devel/oldrel-1) runs on both branches.
- Commit messages follow conventional-commit style seen in history: `fix:`, `chore:`, `ci:`.

## Misc

- `revdep/` holds revdepcheck output (reverse dep: olsrr) — only relevant before CRAN release.
- `roadmap/`, `TODO.md` are maintainer notes, not specs.
- `ds_launch_shiny_app()` just wraps `xplorerr::app_descriptive()` and checks many Suggests packages at runtime via `check_suggests()`.
